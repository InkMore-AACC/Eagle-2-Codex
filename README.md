# 库 · Eagle

连接本机运行中的 Eagle，在 Codex 右侧浏览素材、管理标签与提示词，按需分析或创作。它是网页素材面板，不是完整 Eagle 原生窗口。

当前版本：`1.0.0+codex.20260912082115`。两个插件独立安装、独立运行，不自动互相同步。

## 下载和安装

1. Windows 电脑准备好 **Codex 桌面客户端、Python 3.10 或更新版，以及支持 `codex plugin add` 的 Codex CLI**。安装了桌面客户端不代表终端一定能找到 CLI。
2. [下载完整安装包](https://github.com/InkMore-AACC/Eagle-2-Codex/archive/refs/heads/main.zip)，先完整解压，再进入有 `安装插件.cmd` 和 `install.py` 的那一层目录。不要只下载 plugin 子目录，也不要在压缩包内直接运行。
3. 双击 **安装插件.cmd**，等窗口明确显示“安装成功”。安装器会在你的用户目录生成本机路径，不使用作者电脑的路径。通常不需要管理员权限。
4. 在 Codex 中**新建任务**，发送：**打开 Eagle 图库**。
5. 保持 Eagle 已启动并打开自己的资源库，再让 Codex 打开面板。不要手动运行 migrate 导入案例，除非你确实需要它。

Eagle 需要后台运行，可以最小化。插件通过本机 Eagle API 读取和写入素材，不需要新的 Codex 启动器。

安装失败请看 [安装与排错](docs/安装与排错.md)。**预检查通过不等于安装成功；安装成功也不等于 Eagle 或图库连接已经验证。**

## 用法示例

- “读取我选中的图片，分析它们的提示词写法。”
- “分析这些图片的配色。”
- “用图1的配色、图2的构图，制作一张篮球海报。”
- “反推这张图片的提示词。”——完成后询问是否入库，确认后自动命名、分类并保存。

选中素材本身不会发送消息或开始生成。每个任务保存独立选择，不要复制其他任务带 `task=` 的完整网址。固定本地端口为 `18765`。

## 已实现的功能

- 原比例瀑布流、图片尺寸滑杆、自动加载、可见卡片数量限制，减少长列表负担。
- 一个搜索框搜索名称与标签；顶部文件夹选择与筛选中的文件夹选项同时保留。
- 颜色、标签、文件夹、形状组合筛选；选颜色时优先按匹配度排序。其他情况下按名称、日期或扩展名排序。
- 名称、扩展名、标签、提示词显示开关；名称与扩展名同一行显示。
- 单击选中并显示详情，双击图片放大；双击名称和标签编辑。卡片提示词双击编辑，详情和放大框提示词单击编辑。
- 点击编辑框外：没改动直接退出，有改动询问保存；详情栏可拖动宽度。
- 参考栏不限六张，缩略图保持比例，悬停展示名称、标签和提示词。
- 提示词反推后确认入库，保存前检查冲突，重试避免重复导入。

## 图片反推与保存规则

“图片反推”“看图写提示词”“还原/提取生成提示词”等意图均可触发 Skill，支持上传图片、截图、外部参考图，以及其他 Skill 已完成的反推。复用已有分析结果，不重复分析。触发依赖 Codex 识别并调用 Skill，不是强制拦截客户端所有对话。

反推完成后询问是否将本次图片、名称、标签和提示词存入图库。你确认后，Codex 根据画面内容拟定简短名称和分类标签，再调用保存工具；拒绝或未回答不写入。已有条目更新，外部本地原图复制入库，保留源文件。拿不到真实本地图片时不会假称导入成功。

Eagle 版更新原条目名称、注释和标签；素材不在 image2.5参考 时维护该文件夹中的副本。外部图片复制到 image2.5参考，不创建分类子文件夹，分类使用标签。

两版都启用而目标不清楚时，先选择存到哪一版，不自动存两份。单纯看图识别、OCR、分析配色、阅读已有提示词和普通生图不额外触发反推。生成默认只借鉴已有提示词写法；只有明确要求参考原图，才向生图工具传入图片。本次创作改写不覆盖原图反推提示词。

## 数据与备份

仓库 assets 仅保留原始公开案例素材，不包含作者其他 Eagle 私人图片或任务记录。安装不会自动导入这些案例。公开案例图片约159 MiB，需遵守原素材来源和许可说明；详见 THIRD_PARTY_NOTICES.md。自己的图片和注释仍保存在自己的 Eagle 资源库里。

插件安装在 `%USERPROFILE%\plugins\library-hub`。任务选择和保存重试记录位于 `%USERPROFILE%\Documents\Codex\LibraryData`；备份时同时保留这个目录和完整 Eagle 资源库。 升级重新运行安装器，图库资产不随插件覆盖；安装器保留旧插件备份。不要把运行配置提交到 GitHub。
