# 库 · Eagle

当前保留版本：`1.0.0+codex.20260912011749`。这是 Codex 的本地素材库插件，不是 Eagle 原生窗口的嵌入版。

## 安装和打开

需要 Windows、Python 3.10 或更新版、可调用的 Codex CLI，以及已启动的 Eagle。完整下载并解压本仓库，双击 `安装插件.cmd`。安装器会配置本机路径并安装到个人插件市场；为刷新缓存会生成新的时间后缀，不改变插件代码。

在 Codex 新任务中说“使用 library-hub 打开当前任务的图库”。界面在右侧浏览器打开。网址中的 task 参数对应当前任务，不要把某个任务的完整网址复制到另一任务。

## 使用

- 名称与标签共用搜索栏；顶部文件夹选择与筛选里的文件夹选择同时保留。
- 原比例瀑布流、预览尺寸滑杆、自动加载、可见卡片上限120张。
- 显示开关控制名称、扩展名、标签和提示词；排序支持名称、日期、类型及升降序。日期当前实现按 Eagle modificationTime 排序。
- 颜色、标签、文件夹、形状可组合筛选；启用颜色筛选时优先按颜色相似度排序。
- 单击卡片查看右侧详情；双击图片放大。双击名称和标签原位编辑；卡片提示词双击编辑，详情和放大框中的提示词单击编辑。点击编辑区域外，无修改退出，有修改询问保存。保存经 Eagle 接口并回读校验。
- 详情栏可拖动宽度。放大框外点击关闭。
- 点击“用作参考”加入当前任务选中列表，不设六张上限。顶部小缩略图保持原比例，多图横向滚动；悬停显示完整信息卡片和取消按钮。清空选择不会删除素材。

## Skill 与创作规则

选中素材可用于提示词分析、配色研究、信息提取和创作，不会自动执行任务。

生成图片时默认只借鉴选中素材的现有提示词写法，不查看或传入原图。只有用户明确要求用图片作参考，才将指定原图传入生成工具。分析配色等任务按要求读图；分析不自动保存到 Eagle。缺少提示词时不自动反推。图片生成由 Codex 内置工具完成，插件不提供模型或 API 密钥。

## 数据与备份

安装位置为用户目录下的 `plugins/library-hub`。运行数据位于 `Documents/Codex/LibraryData`，其中 selections 是按任务隔离的小记录，仅保存素材ID、库路径和时间。图片及注释保存在 Eagle 中。

重装前需另行备份完整 Eagle 资源库和 LibraryData。本仓库不包含用户的运行配置、私人选图记录或后续新增素材。插件内 assets 是原始公开案例副本，供现有迁移功能使用，保留其来源说明。安装不会自动迁移或覆盖 Eagle 素材。

Eagle 必须后台运行，可以最小化；完全退出时当前版本不支持离线浏览。固定 Codex 左侧入口、完整原生 Eagle 嵌入及附件自动关联尚未实现。

## 验证范围
